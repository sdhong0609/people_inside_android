# 피플인사이드 (People Inside) - 팀 프로젝트

- PlayStore : https://play.google.com/store/apps/details?id=com.beside153.peopleinside

    - 현재 서버 기한 만료로 앱 정상작동하지 않음

<br>

## 📝 프로젝트 소개

* 사용자의 MBTI에 기반하여 영화 및 드라마 콘텐츠를 추천해주는 앱 서비스입니다.
* 사용자는 콘텐츠를 검색하고 콘텐츠에 대한 평가를 남길 수 있습니다. 마음에 드는 콘텐츠는 북마크도 가능합니다.
* 다른 사람들과 의견도 나눌 수 있는 커뮤니티 기능도 포함하고 있습니다. 글을 작성할 수 있고 다른 사람의 글에 댓글도 남길 수 있습니다.
* 마이페이지에서 사용자가 북마크한 콘텐츠와 평가한 콘텐츠를 확인할 수 있습니다.

<br>

## 👥 팀원 구성
기획 2명, 디자인 2명, 서버 2명, iOS 1명, Android 1명

<br>

## ✅ 수행 업무 : Android 앱 전체 개발  
- MBTI 기반으로 추천하는 콘텐츠 표시 (홈 화면)
- 콘텐츠 검색
- 콘텐츠 별점 남기기 및 감상 작성
- 마이페이지
- 커뮤니티
- 카카오 계정을 통한 회원가입 및 로그인

<br>

## 🤖 Android 기술 스택

| 카테고리         | 기술 스택                                         |
|----------------|------------------------------------------------|
| UI             | XML                                            |
| Architecture   | MVVM, Single Module                            |
| DI             | Hilt                                           |
| Network        | Retrofit                                       |
| Image          | Glide                                          |
| Asynchronous   | Coroutines                                     |
| Jetpack        | ViewModel, LiveData, Navigation, DataBinding   |
| Logging        | Timber                                         |
